# Operator Guide

## First Deployment

1. Confirm the client already uses (or has completed the equivalent of)
   `cloud-itonami-iso3166-jpn` for general Japan market-entry; this repo is
   an agency-specific supplement, not a substitute.
2. Register the client's intake: business type, whether the operator
   is a foreign investor, whether the delivery involves cross-border
   goods, prior filing/compliance history in Japan if any.
3. Run the advisor in read-only mode against Ministry of Finance's
   (財務省) published guidance.
4. Compare the checklist against the client's current documentation
   for each applicable track (全省庁統一資格 status, 会計法/予算決算及び
   会計令 tender-method classification always apply; FEFTA
   prior-notification screening only for foreign-investor engagements
   in a designated/core sector; customs/tariff import declaration only
   for cross-border-goods deliveries).
5. Enable gated filing/compliance-draft assistance once the
   MOF Procurement Compliance Governor contract is trusted; actual
   submission always requires human sign-off.

## Minimum Production Controls

- client-owned data store for compliance documents
- clear provenance (official MOF source citation) for every
  requirement surfaced
- approval workflow for any filing, registration, or compliance-program
  submission
- named referral relationship with Japan-licensed counsel or a registered
  agent for anything beyond checklist/draft assistance
- monthly audit export

## Certification

Certified operators must prove data provenance, audit traceability, that
automated actions cannot bypass the MOF Procurement Compliance
Governor, and a working referral relationship with Japan-licensed
counsel or a registered agent for whatever licensed representation
Japanese law requires for actual MOF filings.
